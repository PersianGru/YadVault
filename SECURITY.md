# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private vulnerability
reporting on this repository (*Security → Report a vulnerability*) and include what you found,
how to reproduce it and the version. You will get an acknowledgement within a week and a fix or
a plan as soon as the issue is understood.

## What counts

Anything that lets someone read or change an archive without the owner's account, leaks message
content to a place the owner did not choose, bypasses the read-only tools, or runs code from
imported content. The threat model is in [docs/security.md](docs/security.md).

## Supported versions

The latest release. Older releases get fixes only when upgrading is not reasonable.
